# Rocky Mountain Cafe Website

A website inspired by the Rocky Mountain Cafe Facebook page for LaPorte, IN.

## Location
- **Address:** 209 Lincolnway, LaPorte, IN, United States, Indiana
- **Email:** rockymountaincoffee@yahoo.com
- **Hours:** Open from 6am-5pm, 7 DAYS A WEEK
- **Price Range:** $$

## Features

### Website Sections
1. **About** - Business information, contact details, and hours
2. **Highlights** - Key features (in-store pickup, drive-thru)
3. **Menu** - Featured food and drink items
4. **Posts** - Latest updates and daily specials
5. **Photos** - Gallery of establishment photos
6. **Reviews** - Customer testimonials and ratings

## Design
The website is inspired by the Facebook page design with a modern responsive layout that adapts to mobile and desktop screens.

## Tech Stack
- HTML5
- CSS3 (with Flexbox/Grid)
- Font Awesome Icons
- Google Fonts (via system fonts)

## Running the Website
Simply open `index.html` in a web browser. For a local server, you can use:
```bash
cd /home/lethalx/Documents/rocky-mtn-cafe-website
python3 -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
